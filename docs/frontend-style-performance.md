# 全站样式与前端性能验证

验证日期：2026-09-08。后端 API、测速算法及依赖保持不变。

## 测量方法

在同一台开发机、同一 Node/Vite 环境下分别执行生产构建，通过本地 Vite preview 提供改造前后页面，使用 Chrome headless、1440 × 1100 视口，无网络或 CPU 限速。

运行详情使用固定模拟 API：统计节点待分析、3 个节点、10,000 条按 ID 排序的日志。每个版本独立浏览器，连续导航 3 次取中位数。导航耗时从测试开始导航准备到当前任务标题可见，并包含相同的 100ms 等待；展开耗时从点击详情到日志首行可见。资源体积为页面实际请求的 JS/CSS 文件逐个 gzip 后相加，不包含图片和 API 数据。

导航原始样本：改造前 762 / 994 / 876 ms，改造后 295 / 248 / 242 ms。展开原始样本：改造前 320 / 218 / 270 ms，改造后 191 / 119 / 116 ms。

登录页 JS 增加 791 B，CSS 减少 2,358 B；统计运行页 JS 减少 85,002 B。时间数据是本地模拟场景结果，不代表生产环境接口延迟或远端设备性能。

## 回归范围

- 前端 38 个测试文件、185 项测试通过，包含自动推进、分析与报告入口、日志重连去重、日志分页、折叠卸载、异步终端命令排队和终端 resize 去重。
- 类型检查、生产构建、版本元数据校验和 git diff --check 通过。
- 工作台、测速列表、统计运行详情、资源管理、方案页、登录页和流程编辑器在 1440 / 1024 / 390px 检查；无页面横向溢出，浏览器无未捕获脚本错误。
- 登录表单必填错误、键盘切换焦点和减少动态效果设置检查通过。减少动态效果时页面动画时长降为 0.01ms。
- 终端连接行为使用测试替身验证，未连接真实测速设备。

## 保留的边界

日志仅限制渲染数量，仍在内存中保留本次运行日志，以支持切换节点和历史页。极长运行若出现内存压力，应进一步使用后端日志分页；本次不改变 API 和日志保留规则。已建立终端会话保留，切换标签不会断开连接。
