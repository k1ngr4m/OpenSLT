# 删除运行配置快照展示

## 目标

从运行详情页的节点详情中删除“运行配置快照”信息区块，不再展示方案版本、场景类型、场景版本、资源数、创建人 ID、开始时间和结束时间。

## 范围

- 删除 `RunDetailView.vue` 中“运行配置快照”区块的模板。
- 保留运行详情接口返回的 `config_snapshot` 数据。
- 保留页面标题、接线信息、节点配置和其他依赖 `config_snapshot` 的功能。
- 不修改后端接口、数据模型或运行创建流程。

## 测试

先在 `RunDetailView.test.ts` 增加源码级断言，确认“运行配置快照”标题及其专用样式标记不再存在，并验证测试会在当前实现上失败。随后删除模板区块并运行该测试、前端测试和前端生产构建。

## 发布说明

在 `RELEASES.json` 的 `unreleased` 数组中记录运行详情不再展示运行配置快照。
