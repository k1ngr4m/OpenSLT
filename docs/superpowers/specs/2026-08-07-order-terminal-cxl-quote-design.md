# 发单 SSH 交互与撤销报价动作设计

## 目标

让发单节点的 SSH 终端可以直接输入命令，并在发单动作列表中支持 `cxl_quote`。

## 方案

- 仅移除运行详情中发单节点 `SshTerminalPanel` 的 `read-only` 属性；其他工作流终端保持现状。
- 将 `cxl_quote` 加入后端标准发单动作、请求模型和前端资源配置选项，使资源能力校验、运行时按钮和直接 SSH 输入使用同一动作名称。
- 同步更新仓库内 EF-VI 发单工具仿真桩，使本地和离线联调环境能够识别 `cxl_quote` 及紧凑写法 `cxlquote`。
- 将 `cxl_quote` 与 `cxl_order`、`stop_order` 一样视为高风险动作，点击按钮需要二次确认。
- 不改变已有资源的显式动作配置；资源编辑页可勾选该动作，未显式配置动作的资源会沿用后端标准动作集合。

## 验收标准

1. 发单节点 SSH 终端能够向远端发送键盘输入。
2. `cxl_quote` 能通过资源配置保存，并能出现在支持该动作的运行节点按钮列表中。
3. 后端拒绝不在资源能力中的 `cxl_quote`，并对支持它的资源正常下发。
4. `cxl_quote` 点击时显示高风险确认框。
5. 相关后端测试、前端测试和前端生产构建通过。
