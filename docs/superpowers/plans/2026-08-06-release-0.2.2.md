# OpenSLT 0.2.2 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 OpenSLT 当前未发布变更正式发布为 `0.2.2`，并完成仓库要求的元数据、后端、前端测试与生产构建校验。

**Architecture:** `VERSION` 是唯一应用版本源；`RELEASES.json` 将 `unreleased` 条目移动到最新发布记录。后端 Python 包和前端构建均从这两份根目录元数据读取版本，不另行维护版本号。

**Tech Stack:** Python 3.8+、pytest、Vue 3、TypeScript、Vite、npm。

## Global Constraints

- 版本必须使用不带 `v` 前缀的稳定语义化格式 `MAJOR.MINOR.PATCH`。
- `RELEASES.json` 最新发布版本必须与 `VERSION` 一致，发布记录按新到旧排列。
- 发布日期使用 `YYYY-MM-DD`；本次发布日期为 `2026-08-06`。
- 所有未发布变更必须转入 `0.2.2`，`unreleased` 发布后为空数组。
- 发布前必须运行 `python tools/release_metadata.py`、后端测试、前端测试和生产构建。
- 离线包仅能在符合 RHEL 7.9 x86_64 制包条件的环境生成；当前 macOS 工作区只做源码和构建校验。
